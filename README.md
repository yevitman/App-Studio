# App Studio

간단한 prompt 기반 앱 생성기입니다.

## 사용 방법

1. 생성 탭에서 원하는 앱을 자연어로 입력합니다.
2. 프롬프트 생성 버튼을 눌러 프롬프트를 만듭니다.
3. 생성된 프롬프트를 확인하고 승인하면 미리보기가 생성됩니다.
4. 미리보기 탭에서 수정사항을 입력하고 이미지 첨부 또는 캡처를 사용할 수 있습니다.
5. 버전 탭에서 이전 상태를 복원할 수 있습니다.

## 실행

GitHub Pages 또는 정적 서버로 루트 폴더를 서빙하면 됩니다.

예:

```bash
python -m http.server 8000
```

그다음 브라우저에서 http://localhost:8000 을 열면 됩니다.
